Nutrelia screens

Static mock-ups of every key screen, using sample Indian foods and made-up people. Nothing here is connected to real data. The colours follow your device's light or dark setting. Tags such as Q3 point to a question in review-notes.md where we need your decision.

Website screens come first. Each section shows the desktop website frames (wider than a phone, so scroll sideways inside a frame if your window is narrow). The mobile versions are kept, collapsed under each section as "Mobile version (for later review)". The site will be responsive on any device; see the Responsive rules in the UX spec.

0. Design system

NFR-05NFR-06UI-CAPSection 12 of REQUIREMENTS.md

What to look at: every screen below uses only what is shown here: four text sizes, eight spacing steps, four button types and one colour palette. If a screen looks different from this page, that is a mistake to report.

Macro colours are used for dots, bars and table header underlines only, never as text colour, and the name is always written next to the colour. The status colours always come with words ("left", "over").

Buttons: four types, one size (40 px on the website, 44 px on phone)

Website buttons and inputs are 40 px tall; phone frames keep 44 px tap targets. Only one primary button per page content area. Icon buttons are the same height and always carry a text label for screen readers. Outline and ghost buttons use the brand ink colour; input and outline borders use the field border colour. There is no on-dark button style any more: the menu "Add food" button is its own menu control (see Side menu).
